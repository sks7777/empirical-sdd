documentation site `goempirical.github.io/empirical-sdd/`) stopped responding
with 404 on 2026-10-06. The files in this folder are recovered copies of pages
that were linked from this repository's documentation but are no longer
available online.

Provenance: the upstream repository's browser-cache entries contained only
response headers, not page bodies, so the copies below were recovered from the
public search-engine index of the original GitHub pages. Each recovered file
